# Aplikasi Konverter Suhu (Versi Indonesia)

## Ikhtisar
**Temperature Converter** adalah aplikasi Android sederhana dan intuitif yang dibangun menggunakan **Kotlin** dan **Jetpack Compose**. Aplikasi ini memungkinkan pengguna untuk dengan mudah mengonversi suhu antara satuan **Celsius**, **Fahrenheit**, dan **Kelvin**. Dirancang dengan antarmuka pengguna yang modern dan bersih, aplikasi ini memberikan pengalaman yang lancar untuk konversi suhu yang cepat di mana saja.

## Teknologi yang Digunakan
- **Kotlin**: Bahasa pemrograman utama yang digunakan untuk pengembangan.
- **Jetpack Compose**: Toolkit modern untuk membangun antarmuka pengguna Android native.
- **Android SDK 24**: Versi Android minimum yang didukung (Android 7.0 Nougat).


# Temperature Converter App (English Version)

## Overview
**Temperature Converter** is a simple and intuitive Android application built using **Kotlin** and **Jetpack Compose**. This app allows users to easily convert temperatures between **Celsius**, **Fahrenheit**, and **Kelvin** units. Designed with a modern and clean user interface, it provides a seamless experience for quick temperature conversions on the go.

## Technologies Used
- **Kotlin**: The primary programming language used for development.
- **Jetpack Compose**: A modern toolkit for building native Android UIs.
- **Android SDK 24**: The minimum supported Android version (Android 7.0 Nougat).
